Descripcion

Este proyecto consiste en una API RESTful desarrollada con Flask para la gestión automatizada de un estacionamiento. Permite el control de vehículos, registro de ingresos y egresos, y el cálculo automático de tarifas basado en el tiempo de permanencia.

Tecnologías Utilizadas

Lenguaje: Python
Framework: Flask (Backend)
ORM: SQLAlchemy (Gestión de base de datos)
Base de Datos: MySQL
Entorno Virtual: venv

Estructura del Proyecto

Para este proyecto se aplicó una arquitectura organizada por módulos para facilitar el mantenimiento:
Models/: Definición de las tablas de la base de datos.
Controllers/: Lógica de negocio y manejo de peticiones.
Routes/: Definición de los puntos de acceso (Endpoints).
Config/: Configuración de la conexión a la base de datos.
